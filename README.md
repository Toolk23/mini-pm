# мини ПМ — ИИ-помощник продакт-менеджера интернет-магазина

Хакатон ИИкузница 2026 · трек «Цифровой аватар» · заказчик «Софтлайн Решения».

Агент-следователь: следит за метриками магазина (Яндекс.Метрика), находит устойчивые отклонения,
расследует их по всем источникам (метрики, релизы, бэклог, интервью, конкурентный анализ),
пишет ПМу письмо с доказательствами, создаёт задачу в бэклоге с тегом «сгенерирована ИИ-помощником»
и после релиза сам замеряет эффект.

## Архитектура
```
Память (ingest, rag) → Радар (detector) → Следователь (investigator + LLM) → Курьер (courier) → ПМ
      ▲                                                                       │
      └── загрузка новых исследований (/api/knowledge/upload)              Замер эффекта (effect)
```
- **detector.py** — детерминированная статистика: скользящее среднее, разовые всплески, неполная неделя,
  контрольная группа, окно релизов, реестр разрывов учёта. LLM не считает цифры — только интерпретирует.
- **investigator.py** — сбор доказательств + отчёт (LLM или шаблон, если ключа нет).
- **rag.py** — BM25-поиск по интервью, конкурентному анализу и загруженным файлам (локально, без внешних эмбеддингов).
- **llm.py** — любой OpenAI-совместимый API: YandexGPT, DeepSeek, OpenAI. Логирует токены по шагам.
- **metrika.py** — Reporting API Яндекс.Метрики (тестовый счётчик команды).
- **settings_store.py** — настраиваемые пороги и правила метрик.

## Запуск локально
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать ключ LLM и токен Метрики
.venv/bin/uvicorn backend.app.main:app --reload --port 8000
```
Документация API: [docs/api.md](docs/api.md), Swagger — http://127.0.0.1:8000/docs

## Данные
`data/raw/` — исходные файлы заказчика, не изменяются. Состояние (бэклог, гипотезы, настройки, лог токенов) — `data/state/`.

# Сценарий демо-видео (до 3:00, один дубль)

**Правила организаторов:** одна непрерывная запись, до 3 минут, на данных задачи. Места, где ждём ответ модели,
**можно ускорить** (например, ×4 в QuickTime/iMovie/CapCut). **Нельзя** вырезать, склеивать, подменять фрагменты и добавлять эффекты.
Видео должно открываться по ссылке без запроса доступа (Яндекс Диск или YouTube «доступ по ссылке»).

**Подготовка (за 10 минут до записи):**
1. Попросить бэкенд сбросить стенд, чтобы задачи начинались с T-09 и не было старых расследований.
2. Открыть https://77-233-220-24.sslip.io в Chrome/Safari, масштаб 100%, окно на весь экран, закрыть лишние вкладки.
3. Во второй вкладке открыть почту тестового ящика (туда придёт письмо агента).
4. Запись: QuickTime → Файл → Новая запись экрана → «Записать весь экран», микрофон включён. Говорить сразу во время записи.
5. Сделать 1 репетицию без записи (после неё снова попросить сбросить стенд).

**Длительность** проверить после ускорения: не больше 3:00.
